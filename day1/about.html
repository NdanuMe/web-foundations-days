About QuickNotes

QuickNotes is a simple app for capturing ideas, reminders and to-dos in seconds.

How to use QuickNotes

  1. Open the Home page.
  2. Type your note into the input area.
  3. Save the note to add it to your list.
  4. Edit or delete notes whenever you need to.

Features

  • Fast note creation
  • Simple, clean layout
  • Edit and delete notes
  • Keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + N New note
Ctrl + S Save note
Ctrl + D Delete note
